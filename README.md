# Echoread

Audiobookshelf client app (Flutter) with karaoke-style read-along
transcription, powered by a self-hosted transcription server
(see [`transcription_server/`](transcription_server/README.md)).

## Highlights

- Streams audiobooks from your Audiobookshelf server.
- **Offline mode**: download a whole book (resumable) or single chapters —
  each downloaded chapter is marked with a badge and the book detail screen
  shows how many chapters are on device. Downloaded books play with no
  server connection at all.
- **Read-along**: word-by-word WebVTT karaoke view generated by the
  transcription server (Groq Whisper), which can be hosted on a PC or
  **on an Android phone via Termux**.

## Getting Started

```bash
flutter pub get
flutter run
```

Point the app at your Audiobookshelf URL + token in the in-app settings,
and at the transcription server URL for read-along support.

## Progress / metadata server

User accounts and reading-progress sync (listened chapters, chapter
positions, continue-reading bookmarks) live in a separate repo:
[secureman/metadata-server](https://github.com/secureman/metadata-server) —
a self-hosted FastAPI + SQLite service. Set its URL in the app's setup /
settings screen; the server's README covers hosting (including Termux)
and the API reference.
